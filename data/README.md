# Data folder

The dataset was provided by the client and is **not included** in this repository.

Place it here with this layout:

```
data/
└── ratinopathy/
    ├── data_all.csv      # columns: Unnamed: 0, file, cat
    └── images/           # 1,764 retina images (.jpg)
```

`data_all.csv` maps each image filename (`file`) to its category (`cat`: 1, 2 or 3).
